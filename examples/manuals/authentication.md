# NimbusDesk Authentication

## AUTH-104 expired token
AUTH-104 means the access token has expired. Sign out of NimbusDesk, then sign in again to obtain a new access token. For a service integration, refresh the token using your configured identity provider. Never paste access tokens into support tickets. If AUTH-104 continues after signing in again, verify that the host clock is synchronized using NTP.

## Reset password
To reset your password, select Forgot password on the sign-in screen. Enter the registered email address and follow the reset link. The reset link expires after 20 minutes. Request a new link if the previous link has expired.
