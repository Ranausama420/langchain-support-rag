# NimbusDesk Installation

## Supported Python version
The NimbusDesk sample worker requires Python 3.11 or Python 3.12. Create a virtual environment before installing the worker package. The sample worker is tested on Linux and Windows. This fictional manual describes NimbusDesk, not the support assistant itself.

## Worker installation
Install the NimbusDesk worker with pip install nimbusdesk-worker inside the virtual environment. Set NIMBUSDESK_SERVER_URL to your organization's server address. Start the worker with nimbusdesk-worker start. These are fictional product commands for the sample corpus, not executable installation instructions for this repository.
