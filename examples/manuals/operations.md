# NimbusDesk Operations

## Export diagnostic logs
Use nimbusdesk-worker diagnostics export to create a diagnostic bundle. Remove personal information and credentials before sharing the bundle with support. The bundle includes worker version, timestamps, and recent error codes.

## Backup retention
NimbusDesk retains daily configuration backups for 14 days. Restore a backup from the Administration > Backups screen. Restoring a configuration backup does not restore uploaded attachments. Test restoration in a non-production environment first.
